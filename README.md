# 🛡️ Plithos — AI-Based School Safety Monitoring System

## 📌 Project Overview
Plithos is an AI-powered safety monitoring system designed specifically for **school environments**. It detects abnormal or unsafe behavior using surveillance cameras, YOLO computer vision models, and cloud infrastructure.

The system helps school staff improve monitoring efficiency by automatically detecting incidents such as fights, littering, and fire hazards while generating real-time alerts.

---

## 🎯 Problem Statement
Schools rely heavily on manual monitoring systems, which may fail to detect dangerous or inappropriate behavior quickly. Plithos provides an automated AI-based monitoring solution that detects abnormal activities in real time and supports faster decision-making for school staff and administrators.

## 🚀 MVP Features

### Core Detection Features
- Real-time fight detection using YOLO
- Littering detection using computer vision
- Fire detection for early hazard identification

### System Features
- Cloud-based video processing and storage (AWS)
- Real-time alert generation
- Monitoring dashboard with camera feed status

---

## ❌ Out of Scope
- Facial recognition or personal identification
- Crowd density analytics
- Physical crowd control systems
- Legal compliance certification

---

## ✅ Success Criteria
- Detects three anomaly types (fight, littering, and fire)
- Generates alerts within **3–5 seconds**
- Displays real-time monitoring dashboard
- Runs within AWS free-tier or low-cost limits
